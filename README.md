# LoL Account Manager

Десктопный менеджер аккаунтов League of Legends. Весь код на Rust, интерфейс на
[eframe/egui](https://github.com/emilk/egui).

- Вид «терминала»: таблица аккаунтов с курсором-строкой, моноширинный шрифт, графитовый
  фон и один янтарный акцент. Под таблицей — всё о выбранном аккаунте: ранги с полоской LP,
  счёт, LP за неделю и последние 5 игр
- Управление с клавиатуры: Enter — войти, P — пароль, L — логин, R — обновить, H — история,
  1–5 — подробности игр, / — поиск; полный список — клавиша `?` в приложении
  (см. [Горячие клавиши](#горячие-клавиши))
- Командная строка (`:` или Ctrl+K): «войти dr4g», «пароль benjm», «обновить все»,
  «тег smurf» — с подсказками по мере ввода, по-русски и по-английски; понимает текст,
  набранный не в той раскладке
- Подробности игры: обе команды целиком (K/D/A, участие в убийствах, урон, золото, CS, предметы)
- Архив игр без ограничения количества: каждая игра, которую приложение увидело, сохраняется
  вместе с подробностями обеих команд; окно «Все игры» (`m`) — список, итог, частые чемпионы
- История рангов: LP за неделю в таблице и окно «История ранга» (график с дивизионами,
  изменения, пик, игры за период)
- После каждой игры аккаунт обновляется сам, а в углу появляется карточка: победа или
  поражение, чемпион, K/D/A и сколько LP получено (с анимацией); в шапке — итог сессии
- Экспорт и импорт списка аккаунтов в файл JSON (без логинов и паролей)
- Данные — из запущенного клиента League (без API-ключа) или через официальный Riot API;
  кэш для работы без сети
- Поиск, фильтр по тегам, сортировка по рангу / уровню / имени / дате добавления
- Логин и пароль хранятся в системном хранилище паролей (Windows Credential Manager),
  а не в файлах
- Копирование логина/пароля в буфер обмена с автоочисткой через 30 секунд
- «Войти» (Enter): копирует логин и открывает Riot Client, второй Enter — пароль
- Вкладка «Лобби»: ваша группа и команда в выборе чемпионов с рангами — в том числе
  в ранговых играх, где клиент скрывает имена союзников (как [reveal](https://github.com/steele123/reveal)),
  мультипоиск и профили на OP.GG

> Приложение **не автоматизирует** клиент League и Riot Client: никакого автологина,
> ввода данных или нажатий. Из клиента League данные только читаются. «Войти» лишь
> запускает Riot Client — так же, как ярлык League of Legends на рабочем столе, —
> а логин и пароль вы вставляете сами (Ctrl+V).

## Требования

- **Rust** stable 1.85+ (edition 2024): <https://rustup.rs>
- **Windows:** Visual Studio Build Tools с нагрузкой «Разработка классических приложений на C++»
  (MSVC + Windows SDK). Нужны линкер MSVC и компилятор C для встроенного SQLite.
- **Linux (Debian/Ubuntu):**
  ```bash
  sudo apt-get install build-essential pkg-config \
    libxcb-render0-dev libxcb-shape0-dev libxcb-xfixes0-dev libxkbcommon-dev
  ```
  Для хранения паролей нужен запущенный Secret Service (GNOME Keyring или KWallet).
  Системная libdbus не нужна: keyring работает с D-Bus через чистый Rust (zbus).

## Установка на рабочий стол (Windows)

```powershell
cargo run --example install
```

Собирает оптимизированную версию, копирует её в `%LOCALAPPDATA%\Programs\LoL Account Manager`
и создаёт ярлыки «LoL Account Manager» на рабочем столе и в меню «Пуск». Дальше приложение
открывается двойным щелчком, без консоли и без `cargo`. После изменений в коде — та же
команда: установленная версия обновится (данные и пароли не трогаются).

Окно запоминает размер, положение и сортировку списка (файл `window.ron` в папке данных).
Если ярлык после обновления показывает старую иконку — это кэш значков Windows: он
обновится сам, или выполните `ie4uinit.exe -show`.

У окна нет системной рамки. Перетаскивайте его за шапку (двойной щелчок —
развернуть), размер меняется за края и углы, кнопки «свернуть / развернуть / закрыть» —
справа в шапке. «Прилипание» к краям экрана и Win+стрелки работают как обычно.

## Запуск для разработки

```bash
cargo run              # debug-сборка, логи пишутся в консоль
cargo run --release    # оптимизированная сборка
```

Первая сборка идёт долго (несколько минут): компилируются все зависимости.
Следующие проходят быстро.

Подробные логи:

```powershell
$env:RUST_LOG="debug"; cargo run      # PowerShell
```
```bash
RUST_LOG=debug cargo run              # bash
```

## Как пользоваться

- **Выбор аккаунта:** щелчок по строке или ↑ ↓. Всё, что делается с аккаунтом, относится
  к строке под курсором (янтарной), под таблицей — её подробности.
- **Добавить аккаунт:** `n` или «добавить» справа над таблицей → Riot ID (`Имя#TAG`), регион,
  теги, заметка и, если нужно, логин и пароль. Кнопка «Из клиента» подставляет аккаунт,
  открытый в клиенте League. Приложение проверит, что такой Riot ID существует.
- **Изменить / удалить:** `e` / `Delete`. Удаление спрашивает подтверждение: Enter — удалить,
  Esc — отмена. Сохранённый пароль в форме не показывается: пустое поле — оставить как есть,
  галочка «стереть» — удалить.
- **Логин / пароль:** `l` / `p` копируют их в буфер обмена; через 30 секунд буфер очищается.
- **Войти:** Enter копирует логин и открывает Riot Client (если он уже открыт — выводит его на
  передний план). Вставьте логин (Ctrl+V) и нажмите Enter ещё раз — скопируется пароль,
  вставьте его. Пока ждём второго нажатия, подсказка внизу подсвечена: «enter пароль».
  Если в клиенте уже открыт другой аккаунт, сначала выйдите из него.
- **Поиск** (`/`) ищет по Riot ID, заметке и региону; `t` переключает тег, `s` — сортировку
  (по рангу сверху самый высокий ранг Solo/Duo); Esc сбрасывает поиск и тег. Тег и сортировку
  можно переключать и щелчком по ним над таблицей.
- **Таблица:** регион, ранги Solo/Duo и Flex, LP за 7 дней, последние 5 игр (W — победа,
  L — поражение, · — ремейк) и состояние: «● в клиенте», «обновляется…» или ошибка.
- **Мышью** тоже всё работает: подсказки клавиш внизу — это кнопки.
- **Лобби:** вкладка сама обновляется раз в 2 секунды. В группе — участники с рангами;
  в выборе чемпионов — ваша команда: позиции, чемпионы, ранги; во время игры — та же команда.
  «Скопировать ники» — все Riot ID через запятую; «Мультипоиск OP.GG» открывает всех
  найденных игроков на op.gg в браузере, щелчок по строке игрока — его профиль на op.gg.
  Имена уходят на op.gg только по нажатию. Точка у вкладки «Лобби» в шапке — вы в группе,
  в выборе чемпионов или в игре.
- **Последние игры:** в панели под таблицей — до 5 игр: результат, чемпион, K/D/A, длительность.
  Щелчок по игре или цифра `1`–`5` открывает подробности: обе команды, у каждого игрока —
  чемпион и уровень, K/D/A, участие в убийствах, урон (с полоской относительно лучшего в игре),
  золото, CS, предметы; у команд — убийства, башни, драконы и бароны. Подробности берутся
  из клиента League (если он запущен на сервере игры) или через Riot API; открытая один раз
  игра второй раз показывается сразу.
- **Экспорт / импорт** (Настройки → «Резервная копия списка»): экспорт сохраняет Riot ID,
  регионы, теги и заметки в файл JSON — например, чтобы перенести список на другой компьютер.
  Импорт добавляет аккаунты, которых ещё нет в списке, и сразу загружает их ранги.
  Логины и пароли в файл **не попадают** — после импорта введите их заново («Изменить»).
- **Все игры** (`m` или «все игры» в панели аккаунта): архив — каждая игра, которую приложение
  увидело, без ограничения количества. Сверху итог: игр, побед и поражений, винрейт и самые
  частые чемпионы; Tab — только Solo/Duo, Flex или другие режимы. ↑ ↓ PgUp PgDn — по списку,
  Enter или щелчок — подробности игры, Esc — закрыть. Подробности сохранённой игры
  открываются из архива сразу и без интернета — даже когда клиент её уже не помнит.
- **История ранга:** колонка «7д» — сколько LP получено за неделю, в панели — то же со счётом.
  `h` открывает окно «История ранга»: очередь Solo/Duo или Flex, период 7 / 30 / 120 дней,
  график с полосами дивизионов (наведение на точку — ранг в тот момент), изменение LP, игры,
  пик и список изменений. История копится с момента установки версии с этой функцией:
  приложение записывает ранг каждый раз, когда он меняется при обновлении.
- **После игры:** когда игра заканчивается, приложение само обновляет аккаунт, в который
  выполнен вход в клиенте (если он есть в списке). Справа внизу появляется карточка:
  результат, чемпион, K/D/A, новый ранг и «+19 LP» — полоска LP заполняется от старого
  значения к новому; при повышении — «Повышение!». Карточка исчезает через 14 секунд
  (пока курсор на ней — не исчезает).
- **Сессия** (шапка, рядом с состоянием клиента): победы, поражения и LP аккаунта из клиента
  за игры без перерывов дольше 3 часов.

## Горячие клавиши

Буквы работают в любой раскладке (в русской `з` — это та же клавиша, что `p`). Пока вы
набираете текст — в поиске, командной строке или форме, — буквы не срабатывают.
Зажатая клавиша повторяет только движение курсора: зажатый Enter не запустит «Войти» десять раз.

| Клавиши | Что делают |
| --- | --- |
| ↑ ↓, `j` `k` | выбрать аккаунт |
| PgUp PgDn | на 5 строк |
| Home End, `g` `G` | в начало / в конец списка |
| Enter | войти: логин в буфер и открыть Riot Client; ещё Enter — пароль |
| `l` / `p` | скопировать логин / пароль |
| `c` | скопировать Riot ID |
| `r` / Shift+R, F5 | обновить аккаунт / все аккаунты |
| `h` | история ранга |
| `1` … `5` | подробности последних игр |
| `m` | все игры аккаунта (архив) |
| `o` | профиль на op.gg |
| `e` / Delete | изменить / удалить |
| `n`, Ctrl+N | добавить аккаунт |
| `/`, Ctrl+F | поиск |
| `t` / Shift+T | следующий / предыдущий тег |
| `s` | сортировка: ранг → уровень → имя → дата |
| `:`, Ctrl+K | командная строка |
| Ctrl+1 2 3 | аккаунты / лобби / настройки |
| `?`, F1 | справка по клавишам |
| Esc | закрыть окно или командную строку, сбросить поиск и тег |

На экранах «Лобби» и «Настройки» работают только Ctrl+1 2 3, командная строка и справка.

### Командная строка

`:` или Ctrl+K открывает строку внизу окна. По мере ввода над ней появляются подсказки:
↑ ↓ — выбрать, Tab — дописать, Enter — выполнить, Esc — закрыть. Аккаунт ищется по любой
части Riot ID; если его не назвать, команда относится к выбранному.

| Команда | Что делает |
| --- | --- |
| `войти dr4g` (`login`) | логин в буфер и открыть Riot Client |
| `пароль benjm` (`password`), `логин …` (`user`), `ник …` (`nick`) | скопировать пароль / логин / Riot ID |
| `обновить …` (`refresh`), `обновить все` | обновить аккаунт / все |
| `история …` (`history`), `opgg …` | история ранга, профиль на op.gg |
| `игры …` (`games`) | все игры аккаунта (архив) |
| `изменить …` (`edit`), `удалить …` (`delete`), `добавить` (`add`) | форма аккаунта |
| `тег smurf` (`tag`), `тег все` | фильтр по тегу |
| `сортировка имя` (`sort name`) | ранг, уровень, имя или дата |
| `аккаунты`, `лобби`, `настройки`, `помощь` | экраны и справка |
| `benjm` | просто часть ника — перейти к аккаунту |

Набрали команду не в той раскладке — тоже сработает: `djqnb dr4g` — это `войти dr4g`.

> **Про имена в ранговом выборе чемпионов.** Клиент League их скрывает специально.
> Вкладка «Лобби» берёт их из чата Riot Client — так же, как reveal. Riot не одобряет
> такие программы: используйте на свой риск. Приложение при этом только читает данные:
> не принимает игру, не доджит и ничего не нажимает в клиенте.

## Откуда берутся данные

Для каждого аккаунта приложение выбирает источник само:

1. **Клиент League of Legends (LCU)** — если он запущен, в нём выполнен вход и его сервер
   совпадает с регионом аккаунта. API-ключ не нужен, лимитов нет, ответ за доли секунды.
   Через клиент видны не только свой аккаунт, но и любые игроки того же сервера,
   поэтому смурфы с того же сервера тоже обновляются.
2. **Riot API** — если задан API-ключ (необязательно). Нужен для аккаунтов других серверов
   и чтобы обновлять данные при закрытом клиенте.
3. Иначе показываются последние сохранённые данные и подсказка, что запустить или настроить.

Аккаунт, в который выполнен вход в клиенте, помечается «в клиенте» и обновляется сам,
как только клиент его покажет, и после каждой игры (клиенту нужно несколько секунд, чтобы
получить новые LP, поэтому приложение пробует до трёх раз: через 3, 12 и 40 секунд).

**Игры** загружаются вместе с рангами из того же источника: из клиента League (история
матчей, 1 запрос) или через Riot API (match-v5). При каждом обновлении приложение берёт
20 последних игр и складывает их в **архив** — таблицу в SQLite без ограничения по количеству.
Поэтому игры не теряются, даже если между обновлениями их было больше пяти; а пока приложение
открыто, аккаунт из клиента обновляется после каждой игры. Игры, которые уже есть в архиве,
повторно не загружаются. Подробности (обе команды) сохраняются тоже: из Riot API они приходят
вместе с игрой, из клиента League фоновый поток догружает их сам (до 20 за обновление, это
локальные запросы). Если игры не загрузились, ранги всё равно обновятся.

Как приложение находит клиент: пока клиент запущен, в папке игры лежит файл `lockfile`
с портом и одноразовым паролем локального API. Папка ищется сама (по настройкам установщика
Riot, затем `C:\Riot Games\League of Legends`). Если игра стоит в другом месте, укажите
папку в **Настройки → Папка игры** (там, где лежит `LeagueClient.exe`) или переменной
окружения:

```powershell
$env:LOLAM_LEAGUE_DIR = "D:\Games\League of Legends"
```

Картинки: иконки профиля — из [Data Dragon](https://developer.riotgames.com/docs/lol#data-dragon)
(официальный CDN Riot), эмблемы рангов, иконки и русские названия чемпионов — из
[CommunityDragon](https://www.communitydragon.org/) (файлы клиента League, выложенные
сообществом; в Data Dragon эмблем нет). Каждая картинка скачивается один раз и дальше
берётся из кэша; список названий чемпионов обновляется раз за запуск, без сети берётся копия.

**Без интернета** приложение работает с тем, что сохранено: ранги, уровни и картинки
берутся из кэша, копирование логина и пароля работает как обычно. На карточке, которую не
удалось обновить, написано «нет связи · обновлено N назад» — видно, насколько данные старые.

LCU — неофициальный API клиента: Riot его не документирует, но чтение данных через него
используют и одобренные приложения (Blitz, Porofessor). Приложение делает только GET-запросы
к `127.0.0.1`.

## Консольные утилиты

### Клиент League (LCU)

```powershell
cargo run --example lcu_check                  # запущен ли клиент, сервер, текущий аккаунт и его ранги
cargo run --example lcu_check -- "Имя#TAG"     # найти любого игрока того же сервера через клиент
```

### Хранилище и API-ключ

```powershell
cargo run --example storage_check -- self-test       # автопроверка SQLite + хранилища паролей

$env:RIOT_API_KEY = "RGAPI-..."                      # один раз: перенести ключ в хранилище
cargo run --example storage_check -- set-key         # ключ проверяется в Riot API и сохраняется
Remove-Item Env:RIOT_API_KEY                         # переменная больше не нужна

cargo run --example storage_check                    # что сохранено
cargo run --example storage_check -- add "Имя#TAG" ru main    # добавить аккаунт (последние слова — теги)
cargo run --example storage_check -- refresh         # «Обновить все»: видно, через что обновился каждый
cargo run --example storage_check -- remove 3        # удалить аккаунт №3
cargo run --example storage_check -- delete-key      # удалить сохранённый ключ
```

`add` и `refresh` работают через тот же фоновый поток, что и окно приложения, и так же
выбирают источник: клиент League или Riot API.

Логин и пароль через командную строку не принимаются: они остались бы в истории
терминала. Их вводят в окне приложения.

### Проверка Riot API

Ключ берётся из `$env:RIOT_API_KEY`, а если переменной нет — из хранилища паролей:

```powershell
cargo run --example riot_check -- "Имя#TAG" euw
cargo run --example riot_check -- "Имя#TAG" euw --repeat 40   # проверка лимитера
```

Регионы: `EUW EUNE NA KR TR RU BR LAN LAS OCE JP ME SG TW VN`
(можно и платформой: `euw1`, `eun1`, `na1`…).
Лог каждого запроса: `$env:RUST_LOG="debug"`.

## Тесты

```bash
cargo test                 # быстрые тесты: без сети и без системного хранилища
cargo test -- --ignored    # сеть, настоящее хранилище паролей и буфер обмена
```

`cargo test --lib -- --ignored images` — настоящая загрузка иконки и эмблем во временную папку.

`cargo test --test backend_e2e -- --ignored` — сквозная проверка фонового потока:
добавление с логином и паролем, копирование в буфер, автоочистка, удаление. Работает на
временной базе и временной записи в хранилище паролей; текст, который был в буфере обмена,
возвращается на место.

## Где взять Riot API key (необязательно)

Ключ нужен только для аккаунтов с других серверов (не того, где запущен клиент League)
и чтобы обновлять данные при закрытом клиенте.


1. Откройте <https://developer.riotgames.com> и войдите своим Riot-аккаунтом.
2. На главной странице (Dashboard) будет блок **Development API Key**.
   Нажмите **Regenerate API Key** и скопируйте ключ вида `RGAPI-xxxxxxxx-...`.
3. Вставьте ключ в приложении: **Настройки → Riot API key → Проверить ключ**.

Что важно знать про ключ разработчика:

- Живёт **24 часа**, потом его нужно перегенерировать на том же сайте.
- Лимиты: **20 запросов в секунду** и **100 запросов за 2 минуты**. Приложение само
  соблюдает лимиты и повторяет запрос после ответа 429.
- Для постоянного ключа можно подать заявку на **Personal API Key**
  (Dashboard → Register Product → Personal API Key). Его тоже нужно просто
  вставить в настройках.

**Никогда не коммитьте ключ** и не вставляйте его в код. Приложение хранит его
только в системном хранилище паролей.

## Где хранятся данные

| Что | Где |
| --- | --- |
| Логины и пароли аккаунтов, API-ключ | Системное хранилище паролей (Windows Credential Manager / Secret Service) |
| Riot ID, регион, теги, заметки, кэш уровня и рангов, история рангов, архив игр | SQLite: `%APPDATA%\lol-account-manager\accounts.db` (Linux: `~/.local/share/lol-account-manager/`) |
| Иконки профиля, эмблемы, иконки и названия чемпионов | `%LOCALAPPDATA%\lol-account-manager\images` (Linux: `~/.cache/lol-account-manager/images`); папку можно удалить — всё скачается заново |
| Размер и положение окна, сортировка | `%APPDATA%\lol-account-manager\window.ron` (обычный текст); файл можно удалить — окно откроется по центру |

Записи в Windows: **Панель управления → Диспетчер учётных данных → Учётные данные Windows →
Общие учётные данные**:
- `riot-api-key.lol-account-manager` — API-ключ;
- `account-<uuid>.lol-account-manager` — логин и пароль одного аккаунта.

Что сделано для безопасности:
- **Ни в SQLite, ни в файлах, ни в логах** нет ни паролей, ни логинов, ни ключа.
  В базе только флаги «есть логин / есть пароль» и случайный UUID записи.
  `self-test` это проверяет: ищет логин и пароль в файлах базы побайтово.
- **Запись в хранилище привязана к случайному UUID, а не к номеру аккаунта.** Если базу
  пересоздать, новый аккаунт №1 не «унаследует» пароль старого.
- **При удалении аккаунта** сначала удаляется его запись из хранилища, потом строка в базе.
- **Типы с секретами не печатают значений:** в отладочном выводе вместо них `***`.
  Ошибки хранилища, внутри которых могут лежать байты секрета, заменяются общим текстом.
- **Буфер обмена:** логин и пароль копируются в буфер напрямую из хранилища паролей, минуя
  окно. На Windows они не попадают в журнал буфера (Win+V) и облачную синхронизацию.
  Через 30 секунд буфер очищается, если там всё ещё наш секрет: то, что вы скопировали
  после, не трогается. При закрытии приложения буфер тоже очищается.
- **Клиент League:** одноразовый пароль из `lockfile` и токен Riot Client (из аргументов
  LeagueClientUx.exe) нигде не сохраняются и не пишутся в лог. Запросы идут только
  на `127.0.0.1`, без прокси и перенаправлений, и только GET.
- **«Войти»** запускает только файл `RiotClientServices.exe` (путь из
  `C:\ProgramData\Riot Games\RiotClientInstalls.json` или стандартный) с аргументами
  официального ярлыка. Логин и пароль в клиент программа не передаёт и не вводит.
- **window.ron** — только размер и положение окна и выбранная сортировка. Внутреннее
  состояние egui (в том числе поля ввода) на диск не сохраняется.
- **Файл экспорта** — только Riot ID, регион, теги и заметка (это проверяет тест).
  Ни логинов, ни паролей, ни служебных идентификаторов в нём нет.
- Папку данных можно переопределить переменной `LOLAM_DATA_DIR` (для тестов).

### Лимиты Riot API

Ключ разработчика: 20 запросов/с и 100 запросов/2 мин, отдельно для каждого
региона (хоста). Клиент держит по два лимитера на каждый хост. Запросы, которые
не укладываются в лимит, ждут своей очереди. Если Riot всё же ответит 429, клиент
подождёт `Retry-After` и повторит запрос (до 3 повторов).

Обновление одного аккаунта — это 4 запроса (account-v1, summoner-v4, league-v4 и список
из 20 последних игр match-v5) плюс по запросу на каждую новую игру, которой ещё нет в архиве,
но не больше 10 за обновление (остальные загрузятся при следующих). Первое обновление — до
14 запросов, дальше обычно 4–6.
Data Dragon — статический CDN без лимитов, ключ туда не отправляется.
